## 🎓 About the Course

**Machine Learning Zoomcamp** is a free, 4-month, hands-on course by DataTalksClub that covers the full lifecycle of a machine learning project — from data exploration to deployment. It is designed for engineers, analysts, and data scientists who want to build real-world ML systems.

### Course Modules

| # | Module | Topics Covered |
|---|--------|----------------|
| 1 | Introduction to Machine Learning | ML fundamentals, CRISP-DM, model selection |
| 2 | Machine Learning for Regression | Linear regression, feature engineering |
| 3 | Machine Learning for Classification | Logistic regression, evaluation metrics |
| 4 | Evaluation Metrics | AUC, precision, recall, F1 |
| 5 | Deploying Machine Learning Models | Flask, Docker, cloud deployment |
| 6 | Decision Trees and Ensemble Learning | Random Forest, XGBoost |
| 7 | Neural Networks and Deep Learning | TensorFlow, Keras |
| 8 | Serverless Deep Learning | AWS Lambda, TensorFlow Lite |
| 9 | Kubernetes and TensorFlow Serving | Containers, orchestration |
| 10 | Capstone Project | End-to-end ML project |
